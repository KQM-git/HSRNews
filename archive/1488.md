# Game Version 4.7 Optimization and Known Issues
## Game Version 4.7 Optimization and Known Issues


Dear Trailblazers,

To provide a better gaming experience, the Crew will constantly make adjustments and improve the game and fix known issues.

### Known Issues

■2026/11/12

- It is a known issue that the audio for some story cutscenes plays abnormally when using certain Xiaomi devices and HyperOS systems. Please wait for fixes to be officially released by the device manufacturer to resolve this issue.

■2026/11/11

- There is a known issue where voice lines and subtitles are out of sync in certain cutscenes during the Trailblaze Mission "Planarcadia — Now, Lay Laughter to All Stars" when the voice-over language is set to English or Korean. This issue will be fixed in a future version.

### Game Updates and Improvements Overview

■2026/11/13

- Fixes an issue where clicking "Battle" under specific circumstances in the "Currency Wars" gameplay would lead to an error display of "already in battle."

- Fixes an issue where some Aha Equipment did not take effect normally in the "Currency Wars" gameplay.

- Fixes an issue where there is a chance of the enhancement interface for the character Clara (Destruction: Physical)'s Ingenious Artificer to be displayed abnormally in the "Currency Wars" gameplay.

- Fixes an issue where the Ultimate effect of the character Xueyi (Destruction: Quantum) became abnormal under certain circumstances in the "Currency Wars" gameplay.

- Fixes an issue where the character Ashveil (The Hunt: Lightning) might cause battle progress to become abnormal after entering combat in the "Currency Wars" gameplay.

- Fixes an issue where some story cutscenes in the Trailblaze Continuance "Astropolis — How to Lose Your Way to the Top: The Zero-Dollar Strategy" could not be played normally when using some platforms.

- Fixes an issue where combat progress might become abnormal after activating the "Astropolis Merchant Guild" Bond under certain circumstances in the "Currency Wars" gameplay.

■2026/11/12

- Fixes an issue where "Smelting Furnace" took effect abnormally on the special equipment "Imploding Singularity" in the "Currency Wars" gameplay.

- Fixes an issue where the game progress became abnormal under certain circumstances during the battle against the enemy "Divine Skull of Indulgence."

- Fixes an issue in the "Currency Wars" gameplay where game progress was abnormal when the character Blade (Destruction: Wind) was in combat under specific circumstances.

■2026/11/11

- Fixes an issue where characters could not perform idle actions normally in the Photo mode under specific circumstances.

- Fixes an issue in the "Interplanar Jump!" of the "Moment of Joy" map, where some stages were abnormal during rechallenges.

- Fixes an issue in the "Aptitude Showcase" character trial event where there was a chance of abnormal game progress in certain trial stages.

- Fixes an issue where, under specific circumstances, the "Interastral Peace Gala: Road to Fame" screen displayed abnormally in the Travel Log when using some mobile devices.

- Fixes an issue where some interfaces in the "Interastral Peace Gala: Road to Fame" event displayed abnormally.

- Fixes an issue where some Space Anchor names and descriptions were incorrect.

- Fixes an issue where some map descriptions were incorrect.
