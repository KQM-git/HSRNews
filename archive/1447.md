# Game Version 4.6 Optimization and Known Issues
## Game Version 4.6 Optimization and Known Issues


Dear Trailblazers,

To provide a better gaming experience, the Crew will constantly make adjustments and improve the game and fix known issues.

### Known Issues

■2026/09/29

- It is known that there is a chance for the Occurrences "Insights from the Universal Dancer" and "Twin Gates of the Maze" to cause game progress to become abnormal in the "Divergent Universe" gameplay. Trailblazers can try restarting the game to resolve this issue.

### Game Updates and Improvements Overview

■2026/09/30

- Fixes an issue in the "Chrysos Maze Grand Restaurant" event where the game screen abnormally turns black after certain story scenes end.

- Fixes an issue in the "Life Sciences Institute" map where the "Furbobo Treasure" in specific "Interplanar Jump!" gameplays could not be obtained under certain circumstances.

- Fixes an issue in the Trailblaze Mission "Astropolis — Knowledge, Silence, Passing By," where it was not possible to reach the Life Sciences Institute through the shuttle under certain circumstances.

- Fixes an issue where the UI interface displays abnormally when using certain Xiaomi devices and systems.

- Fixes an issue where the game progress became abnormal when battling against enemies corroded by the Voracity in the "Divergent Universe" gameplay under certain circumstances.

■2026/09/29

- Fixes an issue where some interfaces in the team lineup system displayed abnormally when using mobile devices.

■2026/09/28

- Optimizes the speed at which owned items are displayed after opening the "Inventory" interface.

- Fixes an issue in the event "Astral Slammers Squad!" where the Collector's Edition Astral Imagea icon displayed incorrectly under certain circumstances.

- Fixes an issue where the photo of the character Hyacine's (Remembrance: Wind) outfit "Warm Cotton Skies" displayed abnormally when placed in the "Photo Wall" of "Collection Showcase."

- Fixes an issue where some images in "Furbobocom" — "Hot Topics" displayed abnormally under certain circumstances.

- Fixes an issue in the "Store" where the "New" notification could not be removed normally on certain interfaces.
